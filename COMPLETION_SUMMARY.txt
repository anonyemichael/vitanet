QUICK START
========================================================================

1. LOAD THE PREDICTOR:
   ```python
   from app.predict import DiseasePredictor
   import numpy as np
   
   predictor = DiseasePredictor()
   ```

2. PREDICT DISEASE (377 symptoms):
   ```python
   symptoms = np.zeros(377)
   symptoms[0] = 1  # anxiety
   symptoms[2] = 1  # shortness of breath
   result = predictor.predict_disease(symptoms)
   # {'disease': 'anxiety', 'confidence_percent': '27.00%'}
   ```

3. PREDICT SEVERITY (vital signs):
   ```python
   result = predictor.predict_severity(
       age=45, gender=0, symptoms_list=[1,1,0],
       heart_rate=75, body_temp=37.5, o2_saturation=98,
       diagnosis=2, systolic_bp=120, diastolic_bp=80
   )
   # {'severity': '1', 'confidence_percent': '82.36%'}
   ```

4. PREDICT BOTH:
   ```python
   result = predictor.predict_both(symptoms, age, gender, ...)
   # Returns both disease and severity predictions
   ```
