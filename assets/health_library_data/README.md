# Health Library Data Store

This directory contains verified medical content, image assets, video catalog, and interactive widget schemas researched from reputable health organizations (NIH, CDC, WHO, MedlinePlus, openFDA, Mayo Clinic, Harvard Health).

## Structure
- `articles/`: Verified health article JSON & Markdown data
- `videos/`: Verified instructional video catalog and embed definitions
- `images/`: High-resolution royalty-free medical and wellness image references
- `interactives/`: Interactive widget specifications (Myth vs Fact, Quizzes, Calculators, Timelines)
